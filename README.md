# 碳索小智——校园碳足迹实验室

给大学生的校园碳账本：算清每一克，再减每一克。

华为开发者大赛 · 智能体创新赛参赛作品（队伍：小白龙），使用华为云码道（CodeArts）以 DeepSeek 模型分 13 步构建。

## 在线体验

直接打开仓库中的 `index.html` 即可使用——单文件、零外部资源、完全离线可用（241,811 字节）。

## 功能（9 个页签）

- **首页 · 数据驾驶舱**：今日碳环、本周账本摘要、风云榜前三、每日一卡、成就徽章墙
- **碳足迹计算器**：饮食 / 出行 / 用电 / 用水 / 一次性用品五板块实时计算，附计算历史
- **减排实验室**：9 个场景全部由同一套系数现算，九场景全开合计日省 15.32 kg
- **植树抵消**：年排放换算植树棵数与占地面积，附十年成长曲线与月度碳预算
- **一周模拟**：七天逐日生成碳周报（周总、趋势、周额度对比）
- **校园风云榜**：6 种校园画像（2.96–10.86 kg/日）同台对比
- **知识卡**：42 张（八大分类）；**知识测验**：40 题，含限时模式与错题本
- **碳账本**：逐日记录、周均统计、Markdown 报告生成；成就徽章 8 枚

## 口径声明

全部系数为教学系数，用于建立数量级概念，不作科研计量。核心验收值：标准学生日总排放 7.71 kg，年排放 2,814 kg 需植树 157 棵。

## 持续进化

本作按可迭代方式构建：数据数组与渲染逻辑分离、样式变量集中管理。后续计划：接入真实校园数据、班级/宿舍挑战赛、账本导出与云端同步。
